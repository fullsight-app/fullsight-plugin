# Security

If you find a security problem in this plugin or in Fullsight, please email [support@fullsight.app](mailto:support@fullsight.app) before telling anyone else, with what you found and how to reproduce it. The same contact is at [fullsight.app/.well-known/security.txt](https://fullsight.app/.well-known/security.txt).

The plugin contains no code that runs on your machine: it's skills (instructions) and the address of Fullsight's MCP server, which signs in as you through your browser.
